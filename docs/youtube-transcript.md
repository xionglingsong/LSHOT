# YouTube 字幕转存与翻译

后台「内容 → YouTube 字幕」（`/admin/youtube-transcript`）可以把本地字幕导入已有的视频记录。先通过已配置的信源采集视频，再按内容 ID、站内保存的链接或标题查找；这里不新增信源。

## 导入文件

1. 从插件导出带时间戳的 Transcript HTML/Markdown，或选择 yt-dlp 导出的 `.vtt`、`.srt`、`.json3` 文件。也支持 `{segments: [{start, end, text}]}` 或同样结构的数组；`start`/`end` 单位为秒，`time` 可使用 `mm:ss` / `hh:mm:ss`。
2. 在后台找到视频，选文件或粘贴字幕，填写**字幕原文**的语言代码，例如 `en`、`ja`、`zh-CN`。人工/自动字幕类型由导入者核实，默认「尚未核实」。一次最多 2 MB、50 万字符。
3. 点击「预览字幕」，检查内容和分段。只有点击「保存字幕并重新评估」才写入。
4. 保存后到「内容诊断」查看修订和处理链路。符合精选、公开、全文展示条件的外文内容，由 worker 的定时翻译任务处理。已有内容也可点「加入翻译队列」，点击「刷新状态」查看译文是否完整；任务错误在后台运行记录中查看。

导入只读取本地文件，不需要在服务器上安装 yt-dlp、使用浏览器 Cookie 或请求 YouTube。无时间戳的普通网页、视频描述和纯文本不能冒充 Transcript。插件导出时需包含时间戳；HTML 使用插件的 `transcript-segment` / `timestamp` 标记，Markdown 支持 `[00:12]`、`**00:12**` 和时间戳链接。

## 保存与展示

滚动自动字幕只在相邻时间重叠时去重，后面再次说出的相同内容仍保留。字幕按停顿、句末、30 秒时间窗和段落长度分段；中文片段衔接不额外插入空格。每段保留指向原视频对应位置的时间戳链接，正文及其译文都可跳转。

保存使用正文修订机制：写入修订历史、重置旧版本的分析状态、加入处理队列并记录管理员操作。相同正文与语言重复导入不会增加修订；预览期间若正文已经更新，保存会提示重新核对。站名、信源、分类、评分门槛、全文许可及精选结果均按现有配置和编辑流程执行。

字幕文件可供内部评估，不代表获得全文再发布授权。站内和 RSS/API 的全文权限仍由信源的 `site_fulltext` / `syndicate_fulltext` 决定；只有来源明确允许时才在信源后台开启。原文与译文都遵循相同的公开读取层。

## 翻译行为

所有模型调用只在 worker 中执行，沿用行业术语提示词、模型配置、回执、预算熔断和关闭时的恢复机制。打开或预览页面不调用模型。

长字幕不再在 6 万字符处截断翻译；导入时先分段，旧脚本生成的超长纯文本段落也会拆成小片段，每批正文翻译最多 3500 字符。富文本片段切分时保留链接与行内格式；极端情况下标签属性本身超出单批限制，该片段保留原文并标为未完成。空译文和丢失时间戳链接的结果不能标记为完整译文。重新运行会复用已支付的同一输入回执；旧版本译文不会显示为新版本译文。

超长字幕可能需要多个批次，费用仍受现有预算限制。定时翻译达到每轮时间预算后会在批次间暂停，下轮从回执继续；手动任务也会在队列到期前停止发起新请求。中途失败或停止 worker 后，已完成请求的回执保留；需要时可再次加入翻译队列。持续不合格的模型结果不会靠重复点击绕过回执而反复付费。
